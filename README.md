# BIREFRINGENCE
[Birefringence](https://www.rp-photonics.com/birefringence.html) is a property of certain crystals (depending on the lattice type), as well as in other materials in certain conditions (for example induced by applied tension) where their index of refraction depends on both polarization and direction of propagation.
Birefringence somewhat restricts the way light can propagate through a medium, since it can only propagate in 2 orthogonally polarized waves (or in one of those 2).
Each wave has its own refractive index.

In uniaxial crystals one of them (extraordinary wave) changes with the incidence angle while the other one (ordinary wave) remains constant. 
One of the main parameters used to describe birefringent media is their birefringence (Δn), which is defined as the difference between both refractive indices (Δn = n<sub>e</sub> - n<sub>o</sub>)

For propagation along the crystal's axis its birefringence is equal to 0, while for propagation perpendicular to the axis its birefringence reaches the highest (absolute) value.
